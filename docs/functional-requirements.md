# Functional Requirements

Core functional requirements for the TODO app:

- Users are able to add tasks to the app.
- Users are able to edit currently existing tasks in the app.
- Users are able to delete tasks from the list.
- Users can sort tasks in the list.
- Users can add due dates to tasks.
- Users can mark tasks complete.
- When a task is created, the creation date and time is shown in a human-readable format.
